My laptop is changing on regular bases between several types of docking stations. 
Somehow Notepad++ struggles over the different positional informations of those docking stations, 
resulting in the fact, that somethimes the window is displayed outside the visual area. 

NppPosReset is just a tiny application which resets the start coordinates of Notepad++ 
to x=10, y=10 which will be, at least in my setup, always visible. 

How to use
Download the .zip from the package/dist folder. 
Extract it.
Run (double click) nppPosReset.exe
